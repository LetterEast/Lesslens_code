# 聚焦与结果

## 自适应软约束（实验功能）

在配置的 `options.adaptiveConstraint` 中设置 `enabled=true` 开启，`strength=0.05` 为温和起点；`0` 完全跳过，`1` 为硬约束。公共默认关闭，关闭后保留原重建行为。日常使用在根目录私有 `reconstruction_config.m` 修改即可。

实现参考 Xu 等人的 [Adaptive constraints by morphological operations for single-shot digital holography](https://doi.org/10.1038/s41598-023-37423-3)，在本项目中独立实现形态学支撑估计，并增加球面照明归一化、多平面迭代内更新和松弛强度。运行不依赖作者仓库或 `local/`；并非原论文单帧实验的直接复刻。恒定图像没有支撑证据时保持该分量，泊松阈值排除空类别并处理零均值。

每轮测量融合后，将复场传播到样品面，去除估计照明，在所有测量对应的有效样品视场并集中更新，包括扩展视场。吸收支撑外振幅向 1 靠近，相位支撑外相位向 0 靠近，再传播回参考面。两者共用 `strength`；支撑每轮重新估计。无测量覆盖的角落不参与阈值统计，也不施加更新。

更新强度在并集最外缘为零，向内按正弦平方渐变；不再在首帧边界突然切换。覆盖帧数经过高斯平滑后用于温和降权，覆盖权重在 0.5 到 1 之间，不按整数帧数跳变。这些权重仅作用于约束修改量，不直接压暗重建振幅。由于空间权重存在，`strength=1` 也不意味着整个视场都执行原论文的硬约束。

- `distance=[]`：在第一轮测量融合后，按现有 `focus` 设置自动聚焦一次，固定为约束距离；手动 ROI 会提前到此时选择并复用。首次复场未充分收敛，距离可能不准；已有可靠聚焦结果时建议直接填写距离（米）。
- `distance=1.36e-3`：示例固定距离，更换样品后需重新设置。正常结果输出仍执行自动聚焦，因此输出距离可能与约束距离不同；两者均保存，不自动追随输出焦点改变约束面。
- `whiteAmplitude=[]`：取首帧有效区域强度的 99.9 百分位开方作为参考面入射振幅估计。也可输入相同数据单位下、经空场标定的正振幅值。厚样品、满视场样品或衍射亮点可能使自动估计偏差明显。
- `edgeWidth=32`：最外缘向内的渐变宽度，单位为样品计算网格像素，必须大于零。增大可使边缘更温和，同时减弱更宽边缘区域的约束；窄小视场可能没有达到完整强度的区域。
- `phaseMode='wrapped'`：保留原相位分割与缩放，兼容已有结果。直接处理 `angle(t)`，跨越 ±π 时可能产生不连续更新。
- `phaseMode='circular'`：可选改进。用 `abs(exp(1i*p)-1)` 估计相位支撑，并在支撑外使用 `p-alpha*sin(p)` 周期松弛，避免将 ±π 跳变当作不连续的相位更新。这是工程改动，不是论文原始硬投影；即使强度为 1，也不是强制归零。不能据此保证暗区真实相位可恢复。
- `phaseMode='off'`：仅保留振幅支撑约束，不修改相位，用于区分伪影是否来自相位约束。不同模式对比时保持 TV、聚焦距离、数据和其它参数相同。

运行目录的 `constraint_autofocus.mat` 保存首次约束聚焦曲线（仅自动距离模式）；`constraint_XXXX.mat` 保存记录迭代时的振幅/相位支撑、视场范围和实际参数。`iteration_XXXX/diagnostics/meta.mat` 也保存约束参数。TV 仍为独立输出处理，比较约束效果时保持其设置一致。高对比度不代表更高分辨率，暗区相位也不保证恢复准确；强约束可能增大测量残差。

## 自动聚焦

每次记录迭代时，程序在 `prior ± halfRange` 上按 `step` 采样，并将参考面复场回传到候选距离。对振幅减去高斯平滑背景（sigma = 2 pixel），取高通振幅的二维 FFT 幅值和作为指标，选择最大值；并列最大时选择第一个采样点。

上述指标对应默认 `focus.method = 'fft'`。聚焦由 `autofocusField` 执行，距离采样规则保持一致。聚焦在样品面 TV 之前评估；图中展示的是最终输出，启用 TV 时包含 TV 处理。曲线比较的是本次搜索内的锐度分数，不能当作不同样品间统一标定的质量分数。

### 分数域指标 ADFrFT

设置 `focus.method = 'adfrft'` 后，对每个回传场计算强度 `I = abs(U).^2`，评价：

```text
score = mean(abs(FrFT_p(I))) + (p-1)*mean(I)
```

其中均值覆盖二维评价区域，`p = focus.frftOrder` 默认 0.8。二维 FrFT 沿两个轴分别计算；非整数阶使用 sinc 插值和 chirp 卷积，整数阶具有单位归一化的离散傅里叶变换约定。

默认在全画布回传后截取中央 256×256 像素评价，以控制 FrFT 的计算量。设置 `cropSize=0` 可评价全图。直接使用 APRW 恢复的复场，保留恢复相位；不重新把输入改成零相位场。

这里接入的是 ADFrFT 指标，搜索仍使用项目原来的等间隔距离网格，没有自动切换到两阶段粗细搜索，也没有做抛物线插值。这样可以明确区分评价指标变化与搜索策略变化。根据最大采样值选择距离，边界/平坦曲线提示同样生效。评价区域、方法和阶数保存在 `autofocus.mat` 中。

ADFrFT 和 FFT 高通指标的数值尺度不同，分数不可直接横向比较；应结合各自曲线形状和选定距离下的图像判断。中央区域如果没有样品，可改用全图评价。

### 手动选取样品区域

`focus.method='adfrft'` 且 `focus.roiMode='manual'` 时，第一次记录迭代会显示在 `focus.prior` 处回传的完整振幅预览。移动和调整矩形后点击“确认区域”，程序在选区内评价所有候选距离，后续记录沿用相同像素坐标，不追踪或缩放样品。

选区至少为 2×2 像素；取消或关闭窗口会停止运行。显式选择手动模式时，即使 `showFigures=false` 也会弹出选区窗口。无人值守运行应使用中央/全图模式，或填写已有 `focus.roiBounds=[xmin ymin xmax ymax]`，跳过交互。

选区坐标相对于完整计算画布，随 `autofocus.mat` 和元数据保存。聚焦结果图用青色矩形标出手动区域，结果回看不需要重新选择；只影响清晰度评价，不改变传播画布或最终裁剪。彩色重建每个通道各选一次；手动模式且坐标为空时，不复用旧通道重建缓存。

`reconstruct` 显示一个可复用的聚焦结果窗口，每次记录后更新：

1. 实际距离采样与指标，标出选定距离和搜索中心。
2. 该距离下输出的振幅。
3. 该距离下输出的相位热力图。

峰值位于边界时提示检查搜索范围；近乎平坦时提示无法确定焦点；单点时明确标注没有进行扫描。程序不会为了获得内部峰值而自动改变搜索范围。

无窗口配置仍默认导出 `diagnostics/autofocus.png`，导出后关闭临时图窗。`view_reconstruction(runFolder)` 可重新查看最新记录，或传入某个 `iteration_XXXX` 路径。旧版只含基本聚焦字段的 MAT 也可查看。

## 输出目录

```text
ResultFolder/APRW_时间戳_参数/iteration_XXXX/
├─ results/
│  ├─ reconstruction.mat
│  ├─ amplitude.png
│  ├─ phase_heatmap.png
│  ├─ amplitude_union.png
│  ├─ phase_heatmap_union.png
│  ├─ originalFOV_amplitude.png
│  └─ originalFOV_phase_heatmap.png
└─ diagnostics/
   ├─ autofocus.mat
   ├─ autofocus.png
   ├─ sample_geometry.mat
   ├─ meta.mat
   └─ adaptive_tv.mat、覆盖/风险/TV 图（启用 TV 时）
```

`autofocus.mat` 包含距离、指标、最佳距离/索引、采样设置，以及边界峰值、平坦曲线、是否执行搜索的标志。`reconstruction.mat` 保存参考面 `field`、样品面 `object`、第一相机物面视场 `objectOriginalFOV`、有效掩膜、覆盖图、裁剪边界和相位显示范围。

相位热力图使用有效区域的 1%–99% 分位范围和 `hot` 色表。PNG 的无效区域填为黑色；MAT 保留数值结果和掩膜。彩色配置为配准保留完整物面画布，融合输出再取共同有效范围。

## 算法约定

- 每个像素由覆盖它的 C 个平面各贡献 1/C；测量区外保留传播预测场。
- 输出几何视场由各传感器边界映射到样品面后的并集决定；`originalFOV_*` 为第一相机的物面视场。
- `options.output.trimPropagationBoundary` 可额外内缩边界，默认关闭。
- 默认自适应复数 TV 根据覆盖、平面间不确定性和边界信息分配约束。
- 几何支持使用点光源、平行平面和当前配准坐标模型，并非严格的衍射信息边界。

## 彩色输出和缓存

`color_fusion_physical.png` 使用强度域与全局白参考；`color_fusion_legacy.png` 保留既有颜色显示方式并增强亮度对比。兼容文件名 `color_fusion_result.png` 对应后者，其他显示方案位于 `comparisons/`。

每个通道的缓存根据准备好的 MAT 路径、大小、修改时间和 APRW 参数匹配。输入格式改为 MAT 后使用新的缓存版本，原始文件夹版本的缓存不会误用。重新准备输入或修改重建参数后将生成新结果。
